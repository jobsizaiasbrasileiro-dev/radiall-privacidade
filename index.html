Politica de Privacidade

Aplicativo: RadiAll | Plataforma: Android | Ultima atualizacao: Agosto de 2026

Resumo: RadiAll e um app de radio que utiliza Google AdMob para anuncios. Preferencias ficam salvas localmente no dispositivo.

1. Dados Coletados

1.1. Identificadores de publicidade

O aplicativo utiliza o Google AdMob para exibir anuncios. O AdMob pode coletar o ID de publicidade do Android (Advertising ID / AD_ID) e outras informacoes de uso para veicular anuncios relevantes e medir sua eficacia. Consulte a Politica de Privacidade do Google para mais detalhes.

1.2. Dados de rede

Para funcionar, o aplicativo acessa a internet e consome streams de audio de emisoras de radio publicas (via Radio Browser). Essas emisoras podem registrar dados de conexao conforme suas proprias politicas.

1.3. Preferencias locais

Suas estacoes favoritas e preferencias de reproducao sao armazenadas exclusivamente no seu dispositivo (armazenamento local), e nao sao enviadas aos nossos servidores.

2. Uso dos Dados

Os dados coletados sao utilizados exclusivamente para:

  • Exibir e personalizar anuncios (AdMob)
  • Garantir o funcionamento da reproducao de radio
  • Melhorar a experiencia do usuario

3. Compartilhamento de Dados

O aplicativo nao vende dados pessoais. Os dados podem ser compartilhados apenas com:

  • Google / AdMob - para entrega de anuncios (conforme a politica do Google)
  • Prestadores de streaming de radio acessados diretamente por voce

5. Seguranca

Adotamos medidas razoaveis para proteger as informacoes, incluindo o armazenamento local de preferencias sem transmissao para servidores proprios.

6. Exclusao de Dados

Para remover todos os dados locais (favoritos e preferencias), desinstale o aplicativo ou limpe os dados dele nas configuracoes do Android.

7. Criancas

O aplicativo nao e direcionado a criancas menores de 13 anos e nao coleta conscientemente informacoes pessoais de criancas.

8. Alteracoes desta Politica

Podemos atualizar esta politica periodicamente. A versao mais recente estara sempre disponivel nesta pagina.
